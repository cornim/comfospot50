# Production Output

The Gerber and drill archive is generated from the project hardware design.
The LCSC identifiers in `bom.csv` identify the selected manufacturing parts;
they are not a license for third-party CAD or datasheet material.

The production outputs are provided without warranty. Verify the board stackup,
component substitutions, assembly orientation, electrical clearances, and
applicable manufacturing requirements before ordering.
