# Contributing

Contributions are welcome through GitHub issues and pull requests.

By submitting a contribution, you certify that you wrote it or have the right
to submit it under the applicable project license. Contributions to software
are accepted under `GPL-3.0-or-later`; contributions to first-party hardware
are accepted under `CERN-OHL-S-2.0`; and contributions to documentation are
accepted under `CC-BY-SA-4.0`.


Do not submit:

- Passwords, API keys, Wi-Fi credentials, private IP addresses, or deployment files.
- Manufacturer manuals or datasheet PDFs.
- CAD files copied from a source whose redistribution terms are unknown.
- Third-party symbols, footprints, or 3D models without provenance and applicable terms.

Hardware contributions must document the source, license, and any required
attribution for embedded library elements. Please use GitHub for project
discussion and contact through the repository's GitHub profile.
