# Security

Please report security issues privately through the repository's GitHub
contact or a private GitHub security advisory. Do not publish credentials,
exploit details, or a vulnerable installation's network information in a
public issue.

Report privately and include:

- Affected component and version or commit.
- Reproduction steps and impact.
- Any relevant logs with secrets and personal information removed.
- A suggested mitigation if known.

If a Wi-Fi password, ESPHome API key, OTA password, or other credential is
exposed, rotate it immediately and report the exposure privately. Removing the
file from a working tree does not invalidate a credential that was previously
shared.

Electrical or physical safety issues should also be reported privately before
public disclosure so that affected users can be warned.
