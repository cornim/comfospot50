# Code of Conduct

Participation in this project is expected to be respectful, constructive, and
focused on improving the software and hardware for its users.

Harassment, discrimination, threats, doxxing, deliberate credential
disclosure, and unsafe instructions presented as verified advice are not
acceptable. Project maintainers may remove content or restrict participation
when necessary to protect contributors and users.

Report conduct concerns privately through the repository's GitHub contact.
